# GrowthFlow | public portfolio demo

This repository contains a self-contained **synthetic** portfolio application. It does not access a live CRM or store private commercial information.

Render configuration: static site, publish directory `.`. The root `index.html` contains the complete public demo.

**Important:** The sample companies, opportunities, amounts, activities and buyer statements are fictional. GrowthFlow is a commercial decision-support demonstration, not a production CRM or a live HubSpot integration.
