# GrowthFlow | public portfolio demo

This repository contains only the self-contained **synthetic** portfolio app. It does not access a live CRM or store private commercial information.

The website is in `site/index.html`. To deploy, connect this repository as a Render Static Site with publish directory `site`, or use `render.yaml`.

**Important:** The sample company, opportunities, estimates and buyer statements are fictional. The project is an account-development decision-support demonstration, not a production CRM.
