# GrowthFlow v1.5 | Commercial Editorial workspace

This repository contains a self-contained commercial decision-support application using **synthetic data**. It does not access a live CRM or store private commercial information.

Render configuration: static site, publish directory `.`. The root `index.html` contains the complete public workspace.

**Important:** The companies, opportunities, amounts, activities and buyer statements are synthetic. The public release uses the Commercial Editorial theme. GrowthFlow is a commercial decision-support demonstration, not a production CRM or a live HubSpot integration.
